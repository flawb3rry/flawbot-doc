# General

## checkin

Lets you build up a watch streak by checking in at consecutive streams.

=== "Usage"

    ```
    !checkin
    ```

=== "Example"

    Input:

    ```
    !checkin
    ```
    Output:
    ```
    {username} has checked in 20 times in a row! You're on fire!
    ```

## followage

Shows how long you have been following the channel.

=== "Usage"

    ```
    !followage
    ```

=== "Example"

    Input:

    ```
    !followage
    ```
    Output:
    ```
    {username}, you have been following this channel for 0 years, 3 months, and 5 days.
    ```

## raid

Displays the raid message.

=== "Usage"

    ```
    !raid
    ```

=== "Example"

    Input:

    ```
    !raid
    ```
    Output:
    ```
    🍓🍓🍓Flawberry Raid🍓🍓🍓
    ```
