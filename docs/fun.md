# Fun

## acceptbattle

Accept a battle when you were challenged.

=== "Usage"

    ```
    !acceptbattle
    ```

=== "Example"

    Input:

    ```
    !acceptbattle
    ```
    Output:
    ```
    {username} launches an epic strike on flawb3rry and emerges victorious! 🏆
    ```

## battle

Challenge another user to a battle.

=== "Usage"

    ```
    !battle <username>
    ```

=== "Example"

    Input:

    ```
    !battle flawb3rry
    ```
    Output:
    ```
    {username} has challenged flawb3rry to a duel! Type !acceptbattle to join the battle!
    ```
